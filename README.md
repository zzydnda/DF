## GitHub 项目参考

下面整理了 3 个海鲜/鱼类电商项目，供学习功能设计和技术实现。此处只保存项目介绍与链接，不包含对方的代码；如需复用代码，请先查看各项目的许可证。

1. [HảiSản.vn — 海鲜市场](https://github.com/but-cmyk/sea-shop)  
   海鲜 C2C 全栈项目，包含鲜货/干货分类、GPS 附近筛选、卖家发布、聊天和管理功能。与你关注的海味干货方向最接近。

2. [Project 3 — Fish Market](https://github.com/collinbarlow-enterprise/Project-3-Fish-Market)  
   鱼类商城学习项目，包含商品目录、详情、购物车、结账和历史订单，适合观察基础网店流程。

3. [Aqua Delight](https://github.com/AnkitShaw-100/Aqua-Delight)  
   功能较完整的海鲜电商项目，包含买家/卖家、商品和订单管理，并尝试用 AI 分析鱼类新鲜度、推荐食谱。
